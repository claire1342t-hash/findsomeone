## 40. 檢舉與停權流程

**已實作（程式）：**

| 流程 | 位置 |
|------|------|
| 檢舉貼文 | `Map.jsx` → `reports` collection + 可選 admin email |
| 檢舉聊天 | `Chat.jsx` → 同上 |
| 管理員審核檢舉 | `Admin.jsx` → 標記「已處理」 |
| 停權 | `Admin.jsx` → 用戶表「停權／解除停權」（`users.isBanned`） |
| 停權生效 | `Login.jsx`、`AuthContext`、`ensureUserNotBanned`、Firestore `isNotBanned()` |

**請你手動驗證（約 10 分鐘）：**

1. 帳號 A 登入 → 地圖開貼文 → 🚩 檢舉 → Firestore `reports` 新增、`status: pending`
2. 帳號 B 進聊天 → ⋯ → 檢舉 → 同上
3. 管理員 `/admin` → 檢舉列表 →「已處理」
4. 管理員 → 活躍用戶 → 對測試帳號「停權」→ 該帳號登入應失敗（`login.errorBanned`）
5. 「解除停權」後可再登入

**說明頁：** About → 聯絡與檢舉；頁尾「檢舉說明」連至 `#about-feature-report`
