# 多語系對齊（以中文為準）

**來源語系：** `messages.js` → `zh`  
**對齊語系：** `en`、`ja`  
**檔案：** `src/i18n/messages.js`（`reportReasons.js` 僅存 reason code，文案走 `report.reason.*`）

## 已修正的主要差異

| 區塊 | 原問題（en/ja） | 對齊後 |
|------|-----------------|--------|
| 首頁四步驟 `feature.*` | 誤譯為「地圖釘選／追蹤常去地點」 | 與中文一致：註冊 → 描述與驗證題 → 等回覆通知 → 確認後匿名聊天 |
| 發布流程 | `New post` / `投稿` | 統一為「Post a search」／「探し人を投稿」 |
| 驗證題說明 `post.verify.hint` | 英文過短、日文過短 | 補齊「僅在場者可答、由貼主判斷」完整語意 |
| 動機 `post.motivation.noticed` | 偏「你很美」 | 「我欣賞你的風格」／ admire style |
| 個人頁回覆 | 按鈕與狀態文案不一致 | 開啟聊天室、人違い、可再試一次等 |
| 結束聊天警告 | 缺少「請三思」 | 英文／日文補上慎重提醒 |
| About | `mechanism` 標題、副標、運作說明 | 對齊「網頁機制」、地點為核心、貼主判斷答案 |
| 管理後台 | Reporter 欄位 | 統一為 Gmail（與中文表頭一致） |
| 頁尾 | 檢舉連結文案 | Reporting guide／通報の案内 |

## 驗證方式

1. 切換語言 zh → en → ja，走一遍：首頁、發布尋找、地圖、個人頁、聊天、About、Admin。
2. 確認首頁四張功能卡標題為 1–4 步驟（非地圖操作教學）。
3. 確認按鈕「發布尋找」在三語皆為同一產品用語。

## 維護約定

- 新增 `messages.js` 鍵時：**先寫 `zh`，再譯 `en`/`ja`**。
- 修改中文文案時，同步更新 en/ja，避免只改單語系。
