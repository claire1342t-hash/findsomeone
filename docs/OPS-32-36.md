## 34. Firestore rules 部署

**規則檔：** `findsomeone/firestore.rules`（含 `isAdmin`/`isBanned`、ownedPosts、responses、notifications 等，見 `docs/FIRESTORE-SECURITY-AUDIT.md`）。

**本機部署（需已 `firebase login`）：**

```bash
cd findsomeone
npm install   # 含 firebase-tools devDependency
npm run deploy:firestore:rules
```

或一次性：

```bash
cd findsomeone
npx firebase deploy --only firestore:rules --project findsomeone-35c7f
```

**部署狀態：** 本機已執行 `firebase deploy --only firestore:rules` 至 `findsomeone-35c7f`（rules 編譯通過並 release）。

**部署後驗證：**

1. Firebase Console → Firestore → **Rules** → 發佈時間為剛才。
2. 用一般帳號在 Console Rules Playground 測試：不可改 `users/{uid}.isAdmin`；不可 `update` notifications。
3. 管理員檢舉 `reports` 的 `update` 仍僅 `isAdmin`。
